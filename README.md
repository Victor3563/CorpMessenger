# CorpMessenger

**CorpMessenger** — это корпоративный мессенджер с веб-интерфейсом, предназначенный для внутренней коммуникации сотрудников компании. Проект реализован с использованием современных технологий и разделён на фронтенд и бэкенд части.

## 🧰 Технологический стек

- **Бэкенд**: [Go (Golang)](https://golang.org/) — высокопроизводительный язык программирования, подходящий для разработки серверных приложений.
- **Фронтенд**: [Vue.js 3 (Composition API)](https://vuejs.org/) — прогрессивный JavaScript-фреймворк для создания пользовательских интерфейсов.
- **WebSocket** — для обмена сообщениями в реальном времени.
- **PostgreSQL** — в качестве СУБД.
- **Docker + Docker Compose** — для контейнеризации и простого развёртывания.
- **Nginx** — для проксирования и работы с HTTPS.

## ⚙️ Основной функционал

- Регистрация и аутентификация пользователей.
- Обмен сообщениями в реальном времени.
- Создание и участие в групповых чатах.
- Уведомления о новых сообщениях (включая счётчик непрочитанных).
- Обнуление счётчика сообщений при входе в чат.
- Веб-интерфейс для общения сотрудников.

## 🚀 Инструкция по запуску локально

### 1. Клонируй репозиторий

```bash
git clone https://github.com/Victor3563/CorpMessenger.git
cd CorpMessenger
cd backend
docker-compose up --build
go run main.go
cd ../frontend
npm install
npm run dev
Открой http://localhost:5173 в браузере.
